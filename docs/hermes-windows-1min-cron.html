3. Put VPN in a Blofin-accepted country

Blofin blocks many jurisdictions. Your VPN exit IP must be in a country Blofin allows. Netherlands and many other EU countries are commonly used accepted exits.

Do this before first private API call

  1. Turn your VPN on.
  2. Choose an exit in a Blofin-accepted country (example: Netherlands / NL).
  3. Confirm your public IP country matches that exit:
Check your IP country in the browser 
https://ipinfo.io
https://ifconfig.co/country
Optional PowerShell check 
curl.exe https://ifconfig.co/country
curl.exe https://ipinfo.io/country
Restricted / not accepted examples include: United States, Canada, China, India, Singapore, UAE, and other locations listed in Blofin’s Terms of Use Restricted Locations. If your VPN lands in a restricted country, Blofin may return an HTML geo/WAF page instead of JSON and trading will fail. Stay on an accepted exit the whole time Hermes is trading.
Why this matters: when the IP is wrong, Hermes looks “broken” even with perfect API keys. Fix VPN first, then credentials, then trades.

4. Paste your Blofin key path (builds the prompt)

Put your Blofin Passphrase / API Key / API Secret in a plain .txt file on your PC. Then paste that full file path below. The prompt updates automatically so you can copy it into cron.

Example credentials file contents 
Passphrase: YOUR_PASSPHRASE
API Key: YOUR_API_KEY
API Secret: YOUR_API_SECRET

Tip: in File Explorer, hold Shift → right-click the file → Copy as path, then paste here (quotes are fine; they get stripped).

Prompt uses placeholder path until you paste yours.

5. Create the cron in the dashboard Cron section

Do this in the browser dashboard only — the Cron section/tab at http://127.0.0.1:9119. Do not create it from Hermes chat.

  1. In the dashboard, open Cron.
  2. Click create / new job.
  3. Schedule: every 1m
  4. Name: blofin-equity-vertical
  5. Provider dropdown: Nous
  6. Model dropdown: tencent/hy free (same free Tencent Hy option shown in the UI)
  7. Delivery: local is fine
  8. Prompt field: paste the personalized prompt from Section 6
  9. Save, then run once from the Cron section to test
Dashboard Cron settings 
Where: Dashboard → Cron section (browser)
Schedule: every 1m
Name: blofin-equity-vertical
Provider: Nous
Model: tencent/hy free
Deliver: local
Prompt: paste Section 6
Keep hermes dashboard running so cron keeps ticking. If you close the dashboard host process, the 1-minute loop stops.
If one tick takes longer than 60 seconds, the next tick can be delayed. That is normal. Do not force bad entries just to “stay busy.”
