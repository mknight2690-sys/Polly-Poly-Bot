0. Tiny word list + first-computer basics

  • Browser — the app for websites. Windows usually has Edge. Mac has Safari. Chrome is fine too. You are reading this page inside a browser right now.
  • Address bar — the long box at the top of the browser where websites like https://... go. Click it, paste a link, press Enter.
  • Copy / Paste — Windows: Ctrl+C copy, Ctrl+V paste. Mac: Cmd+C / Cmd+V. In PowerShell, right-click often pastes.
  • Start menu (Windows) — key with the Windows logo, or the Start button. Type an app name.
  • Spotlight (Mac) — press Cmd+Space, type the app name, press Enter.
  • Blofin — the exchange website where your money and trades live.
  • USDT — “digital dollars” on Blofin. Roughly 1 USDT ≈ $1.
  • VPN — app that changes which country the internet thinks you are in. Required.
  • API key — a password-like key that lets Hermes trade for you (not your login password).
  • Hermes — the free program on your computer that thinks and places trades.
  • Dashboard — Hermes’ control page in your web browser.
  • Cron — a repeating timer. Ours runs Hermes every 1 minute.
  • PowerShell (Windows) / Terminal (Mac) — the text window where you paste install commands.
Before anything else: plug the laptop into power if you can. Keep this tutorial tab open. When a step says Copy, click the Copy button on this page, then paste where the step says.

1. Stop your computer from sleeping (required)

If the computer sleeps, Hermes’ 1-minute loop stops and you miss trades. Do this once now. Leave the laptop open and preferably plugged in while Hermes runs.

Windows (click path)

  1. Click Start → type Power and sleep or Power & battery → open it. (Windows 11 is often: Settings → System → Power & battery → Screen and sleep.)
  2. When plugged in: set Turn off my screen after to Never (or a very long time).
  3. When plugged in: set Put my device to sleep after to Never.
  4. On battery: also set sleep to Never while you are learning (or keep it plugged in).
  5. Optional but recommended — lid: Start → type Choose what closing the lid does → open → for “When I close the lid” set Do nothing (at least while plugged in) → Save changes.

Optional fast PowerShell method (Start → type PowerShell → open → paste with right-click → Enter):

Windows — never sleep (plugged in + battery) 
powercfg /change standby-timeout-ac 0
powercfg /change standby-timeout-dc 0
powercfg /change monitor-timeout-ac 0
powercfg /change monitor-timeout-dc 0
powercfg /change hibernate-timeout-ac 0
powercfg /change hibernate-timeout-dc 0
0 means Never. Screen staying on uses more power — leave the charger connected when Hermes runs overnight.

Mac (click path)

  1. Click the Apple menu () → System Settings.
  2. Open Lock Screen (newer macOS) or Battery / Energy Saver (older).
  3. Set “Turn display off on battery when inactive” to Never (or the longest option) while learning.
  4. Set “Turn display off on power adapter when inactive” to Never.
  5. If you see Prevent automatic sleeping when the display is off (power adapter), turn it ON.
  6. Keep the MacBook lid open while Hermes runs (simplest). Plug into power.

Optional Terminal stay-awake helper (leave this Terminal window open in addition to Hermes):

Mac — keep awake while this runs 
caffeinate -dimsu
caffeinate keeps the Mac awake until you press Ctrl+C in that Terminal or close the window. Run it in a second Terminal while Hermes runs in the first.
Do Section 1 before you leave the computer alone overnight. Sleep = Hermes pauses. Never-sleep + open lid + charger = the 1-minute loop can keep living.

2. Free Proton VPN → Blofin-allowed country

Do this before you sign up for Blofin or buy crypto. Blofin blocks some countries (including the United States, Canada, and Singapore). Free Proton VPN fixes that for most beginners.

Install Proton VPN

  1. Copy this link, paste it into your browser address bar, press Enter:
Proton VPN download 
https://protonvpn.com/download
  1. Click the download button for Windows or macOS (match your computer).
  2. Open your Downloads folder and double-click the installer (Windows: .exe, Mac: .dmg). Click through Next / Install / Open.
  3. If Windows asks “Do you want to allow this app…?”, click Yes. If Mac says the app can’t be opened, go to System Settings → Privacy & Security → Open Anyway.
  4. Create a free Proton account if asked (email + password). Stay on the Free plan — do not pay for Plus unless you want to.
  5. Open the Proton VPN app. On free, you cannot pick a country. You use the big Connect button, then Change server.

Countries free Proton can land on

Free servers exist in: United States, Canada, Mexico, Netherlands, Japan, Romania, Poland, Norway, Switzerland, Singapore. First Connect usually lands on the United States (blocked by Blofin).

Keep these (Blofin allows)

  • Mexico
  • Netherlands
  • Japan
  • Switzerland
  • Norway
  • Romania
  • Poland

Leave these (Blofin blocks)

  • United States (common first Connect)
  • Canada
  • Singapore

Exact free Proton flow

Do this until Proton shows an allowed country:
  1. Hit Connect. Free plan often connects to the United States first.
  2. Wait 1 minute 30 seconds.
  3. Hit Change server. If you land on Mexico / Netherlands / Japan / Switzerland / Norway / Romania / Poland → stop, you’re done.
  4. If still blocked (US / Canada / Singapore): wait 1 minute 40 seconds, then Change server again.
  5. If still blocked: wait 1 minute 50 seconds, then Change server again.
  6. If still blocked: free Proton usually forces a ~10 minute wait. Instead: Disconnect → Connect (likely US again) → wait the 10 minutes → restart from the 1:30 step.
Where is Change server? In the Proton VPN app, after you are connected, look on the main/home screen for Change server (sometimes under Countries). You are not picking a country from a map on free — Proton picks randomly after each Change server. The connected country name is shown in the app near the Connect button (example: Netherlands, Mexico, Japan).
Prove your country (open in browser while VPN is on) 
https://ipinfo.io
https://ifconfig.co/country

Paste one of those links in the browser address bar. The page should show the same country Proton shows. If the browser still says United States, Change server again using the timing above.

Leave Proton VPN connected for the rest of this tutorial and whenever Hermes is trading. If it drops back to US / Canada / Singapore, Blofin will look “broken.” Confirm Section 1 (never sleep) is done. Lid open. Charger in. Loop dies if the PC sleeps.

6. Create Blofin API key (Compendium + Trading + Transfer)

This is how Hermes gets permission to trade your account. VPN must still be on.

  1. Blofin → profile / account menu (top right) → API / API Management.
  2. Click Create API Key.
  3. Choose Connect to Third-Party Applications.
  4. Application Name dropdown: select Compendium (type compendium to find it).
  5. API Key Name: type Hermes.
  6. Permissions — check:
    • Trading (Trade) — required
    • Transfer — required for this setup
    • Read — leave on
    Do not turn on Withdraw for this guide.
  7. Create a Passphrase (like a mini-password). Write it down — you need it in the next step.
  8. Leave IP whitelist empty unless you know you need one.
  9. Confirm with email code and/or authenticator (2FA) if Blofin asks. If you have not set up 2FA yet, Blofin will walk you through it — finish that, then come back to create the key.
  10. Copy API Key and API Secret right away (Secret is shown once). Paste them into Notepad/TextEdit immediately so you do not lose them.
API create checklist 
API Management → Create API Key
Connect to Third-Party Applications
Application Name: Compendium
API Key Name: Hermes
Permissions: Trading ON + Transfer ON + Read ON
Withdraw: OFF
Save Passphrase + API Key + API Secret now
