Polly Poly Bot — Alert Deck Setup

Get the Polymarket Alert Deck running on Windows: install, open the dashboard on http://127.0.0.1:18112, wire CLOB credentials safely, and keep execution dry_run + disarmed until you explicitly choose to arm.

Instant digital access Windows Dry-run first Voice + lag edges
Goal: Deck open in Chrome, paper/alerts working, CLOB connected if you want live later — without spending until you arm.

1. Prerequisites

  • Windows 10/11
  • Python 3.11+ on PATH
  • Chrome (hard-refresh after upgrades: Ctrl+Shift+R)
  • Optional for live later: Polymarket account + USDC deposit + VPN in an allowed country

2. Install Polly

Clone or download the public repo, then install deps:

PowerShell
git clone https://github.com/mknight2690-sys/Polly-Poly-Bot.git
cd Polly-Poly-Bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy credentials\poly_clob.example.txt credentials\poly_clob.txt
Desktop shortcuts (optional): powershell -NoProfile -ExecutionPolicy Bypass -File .\create_desktop_shortcuts.ps1 creates Start Polly / Stop Polly on your Desktop.

3. Start the deck

PowerShell
python run_poly.py
# or: .\Start Polly.bat

Open http://127.0.0.1:18112/ in Chrome. Confirm the build tag (top-right under BANKROLL) matches the README / release you installed.

Do not open a second deck tab in another browser automation tool — one Chrome tab is enough; duplicates confuse voice alerts.

4. Polymarket credentials (safe path)

  1. Copy credentials/poly_clob.example.txt → credentials/poly_clob.txt if you have not already.
  2. Fill PRIVATE_KEY and FUNDER from your Polymarket / proxy wallet setup. Leave derived API_* blank if your agent/onboarding flow derives them.
  3. Never commit, paste into chat, or screenshot full secrets.
Full agent onboarding playbook (derive keys, verify balance) lives in the repo README section “AI agent playbook — get CLOB working for a new user”.

5. Verify dry-run mode

  • Execution boots dry_run + disarmed by design.
  • Watch alerts, lag edges, and mental trailing stops on the deck without real orders.
  • If something looks wrong, stop with Stop Polly.bat / stop_polly.ps1 and check logs/.

6. Daily loop

  1. Start Polly (single instance on port 18112).
  2. Hard-refresh Chrome after any upgrade.
  3. Scan Alert Deck for lag / voice alerts.
  4. Paper or dry-run until you trust the edge.
  5. Stop Polly when done for the session.

7. When (and only when) to arm

Arm live spending only after: VPN allowed country, funded USDC, CLOB verified, and you explicitly want real orders. If you are unsure, stay dry-run.

8. Troubleshooting

  • Port busy: run Stop Polly, then Start Polly again (mutex / single instance).
  • Old UI: hard-refresh; confirm build tag bumped.
  • No CLOB balance: re-check funder/proxy wallet and deposit; do not paste keys into chat.
  • Voice weirdness: close duplicate dashboard tabs.
